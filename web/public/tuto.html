Étape 01

installer.

  • Mac : ouvre FLShortcuts.pkg et suis l'installation.
  • Windows : double-clique sur l'installeur, puis Installer.
  • Bloqué ? Mac : Réglages Système › Confidentialité et sécurité › Ouvrir quand même. Windows : Informations complémentaires › Exécuter quand même.

Étape 02

autoriser.

  • Clique Autoriser : le clavier, puis le son de FL.
  • Le son de FL sert à l'Organiser.
  • Ouvre FL Shortcuts avant FL Studio.
  • Windows : rien à autoriser. Installe loopMIDI si l'accueil le demande.

Étape 05

organiser.

  • Ouvre ton projet dans FL.
  • Appuie sur ⌘⌥O dans FL.
  • Garde la version rangée, ou reviens comme avant.
  • Windows : Ctrl+Alt+O. Sons, Mixer et Playlist rangés par famille, dans une copie. La première fois, il te guide pour relier FL.

Étape 07

au quotidien.

  • L'icône en haut de l'écran ouvre le menu.
