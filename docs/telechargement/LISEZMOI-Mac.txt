FL Shortcuts pour Mac — mode d'emploi
=====================================

INSTALLER
1. Ouvre FLShortcuts.dmg et glisse FL Shortcuts dans le dossier Applications.
   (Ou double-clique FLShortcuts.pkg : il l'installe tout seul.)
2. Premier lancement : macOS peut dire qu'il ne peut pas vérifier l'app.
   Fais un clic droit sur FL Shortcuts dans Applications › Ouvrir, puis « Ouvrir ».
   Sinon : Réglages Système › Confidentialité et sécurité › « Ouvrir quand même ».
3. L'accueil demande deux autorisations :
   - Clavier : clique « Tout autoriser… », coche FL Shortcuts, puis ton mot de passe ou Touch ID.
   - Son de FL (pour l'Organiser) : réponds « Autoriser ».
   « Autorisé » s'affiche dès que c'est fait.

UTILISER
- Tes raccourcis marchent quand FL Studio est la fenêtre devant.
- Le menu est dans l'icône en haut de l'écran : raccourcis, macros, Organiser.
- Rechercher : la barre en haut à gauche de la fenêtre ; l'icône clavier à côté cherche par raccourci.

ORGANISER (ranger un projet de FL)
1. Menu de l'icône › Organiser…
2. La première fois : « Installer le lien », puis quitte FL (⌘Q) et rouvre-le.
3. Clique « Démarrer ». Ne touche pas à FL jusqu'à la fin.
4. Si FL ne répond pas : dans FL, Options › MIDI Settings, règle les 4 cases montrées dans la fenêtre.
L'original de ton projet ne bouge jamais : la version rangée est une copie (« ton projet_2.flp »).

METTRE À JOUR
Remplace l'app dans Applications par la nouvelle. macOS peut redemander l'autorisation du clavier.

DÉSINSTALLER
Menu de l'icône › Désinstaller FL Shortcuts… (rien ne reste sur le Mac).

UN PROBLÈME ?
Dans l'app : Aide › Écrire à l'équipe (le diagnostic part avec ton message, jamais le nom de tes sons).

Les fichiers .sha256 servent seulement à vérifier le téléchargement (facultatif).

FL Shortcuts for Mac — quick guide

Install: open FLShortcuts.dmg and drag FL Shortcuts to Applications (or open FLShortcuts.pkg).
First launch: right-click the app › Open, then Open (or System Settings › Privacy & Security › Open Anyway).
Allow the keyboard (Accessibility) and FL's sound when the welcome window asks.
Shortcuts work when FL Studio is in front. Everything else is in the menu bar icon.
Organize: menu bar icon › Organize…, « Install the link », quit and reopen FL, then « Start ».
Problem: Help › Write to the team, inside the app.
