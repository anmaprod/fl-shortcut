Step 01

Install

  1. 1Run FLShortcuts-Windows-Setup.exe.
  2. 2If Windows says “Windows protected your PC”: More info › Run anyway.
  3. 3Follow the installer to the end. FL Shortcuts starts near the clock, at the bottom right.

Step 03

Organize

  1. 1Open your project in FL, then the icon near the clock › Organize…
  2. 2The first time: Install the link, then close FL and open it again.
  3. 3First check the 4 MIDI Settings boxes, just below.
  4. 4Start, then check the preview (you can drag families and sounds) and Organize.
  5. 5At the end, “Keep the organized version?”. Yes: the old version goes to the Trash. Go back: the organized version goes there instead.
  6. —Nothing is deleted for good: until you empty the Trash, you can get the project back from it.

The 4 MIDI Settings boxes

In FL: Options › MIDI Settings. Set these 4 boxes, then click “Start” in Organize.

1Output: a Port number (e.g. 7).
2Input: the same Port number. Any number, as long as both are the same.
3Input: click “FL Shortcuts Link”, then turn on Enable.
4Controller type: FL Shortcuts.
